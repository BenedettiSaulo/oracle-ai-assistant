# ☕ Brasil JUG AI Assistant
### *Empowering the Brazilian Java Community with Oracle 26ai & OCI Generative AI*

This project is a **RAG (Retrieval-Augmented Generation)** system designed to act as an intelligent assistant for the **Brasil JUG (Java User Group)**. It allows community members to ask questions in natural language about past and future events, retrieving accurate information directly from an **Oracle Database 26ai** using **AI Vector Search**.

---

## 🚀 Key Features

* **Semantic Search:** Uses vector embeddings to understand the meaning behind user queries, going beyond simple keyword matching.
* **AI Vector Search:** Leverages the native `VECTOR` data type and `VECTOR_DISTANCE` functions of **Oracle Database 26ai**.
* **Automatic Language Detection:** The assistant detects the user's language (English or Portuguese) and responds in the same language, ensuring a seamless experience for the global Java community.
* **Timezone Awareness:** Handles complex event schedules using `TIMESTAMP WITH TIME ZONE` to ensure accurate date reporting across different regions.
* **OCI Generative AI Integration:** * **Embeddings:** Powered by `cohere.embed-multilingual-v3.0` (1024 dimensions).
    * **Chat/Reasoning:** Powered by `meta.llama-3.3-70b-instruct`.

---

## 🏗️ Architecture Overview

The system follows the RAG architectural pattern, divided into two main pipelines:

1.  **Ingestion Pipeline:** Raw event data (JSON with ISO-8601 dates) is processed, enriched with metadata, converted into high-dimensional vectors via OCI Generative AI, and stored in Oracle 26ai.
2.  **Retrieval Pipeline:** User questions are vectorized, a similarity search is performed in the database using **Cosine Distance**, and the relevant context is sent to the LLM to generate a precise, grounded response.

## ⚙️ Setup & Configuration

### 1. Database Schema
Run the following SQL to prepare your Oracle 26ai environment with timezone support:

```sql
CREATE TABLE events_brazil_jug (
    id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    event_name VARCHAR2(255),
    full_description CLOB,
    event_date TIMESTAMP(6) WITH TIME ZONE,
    event_location VARCHAR2(255),
    registration_link VARCHAR2(500),
    vetor_embedding VECTOR(1024, FLOAT32)
);

CREATE VECTOR INDEX idx_jug_events_vector ON events_brazil_jug (vetor_embedding)
ORGANIZATION INMEMORY NEIGHBOR GRAPH
DISTANCE COSINE;
```

### 2. Environment Variables
For security, sensitive data must be set via environment variables:

| Variable | Description |
| :--- | :--- |
| `DB_PASSWORD` | Password for the database user |
| `WALLET_PATH` | Local path to the Oracle Wallet (TNS_ADMIN) |
| `OCI_COMPARTMENT_ID` | OCID of your OCI Compartment |
| `OCI_CONFIG_PATH` | Path to your `.oci/config` |

## 🚦 How to Use

### 1. Data Ingestion
Populate your knowledge base by sending a POST request to `/api/admin/saveAll`:

**Endpoint:** `POST /api/admin/saveAll`
**Payload:**
```json
[
  {
    "name": "English Conversation + Review Java Code",
    "description": "Event focused on English practice and Java code review.",
    "date": "2026-03-26T20:00:00-03:00",
    "local": "remote",
    "link": "https://discord.gg/bW2Camnr"
  }
]
```

### 2. Asking the Assistant
Interact via `/api/v1/assistant/ask` (The response will match your question's language):

**Request (PT-BR):** `"Quando será o próximo evento de conversão em inglês?"`
**Response:** `"O próximo evento English Conversation + Review Java Code está agendado para o dia 26 de março de 2026 às 20:00 (UTC-3)."`

**Request (EN):** `"What are the next community study groups?"`
**Response:** `"The study group sessions are held every Tuesday at 19:00 (UTC-3) via Discord."`
