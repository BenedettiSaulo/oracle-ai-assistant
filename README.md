# ☕ Brasil JUG AI Assistant
### *Empowering the Brazilian Java Community with Oracle 26ai & OCI Generative AI*

This project is a **RAG (Retrieval-Augmented Generation)** system designed to act as an intelligent assistant for the **Brasil JUG (Java User Group)**. It allows community members to ask questions in natural language about past and future events, retrieving accurate information directly from an **Oracle Database 26ai** using **AI Vector Search**.

---

## 🚀 Key Features

* **Semantic Search:** Uses vector embeddings to understand the meaning behind user queries, going beyond simple keyword matching.
* **AI Vector Search:** Leverages the native `VECTOR` data type and `VECTOR_DISTANCE` functions of **Oracle Database 26ai**.
* **OCI Generative AI Integration:** * **Embeddings:** Powered by `cohere.embed-multilingual-v3.0`.
    * **Chat/Reasoning:** Powered by `meta.llama-3.3-70b-instruct`.
* **Community Focused:** Tailored specifically for the Brasil JUG context with specialized system prompts.

---

## 🏗️ Architecture Overview

The system follows the RAG architectural pattern, divided into two main pipelines:



1.  **Ingestion Pipeline:** Raw event data (JSON) is processed, converted into high-dimensional vectors (1024 dimensions) via OCI Generative AI, and stored in Oracle 26ai.
2.  **Retrieval Pipeline:** User questions are vectorized, a similarity search is performed in the database, and the relevant context is sent to the LLM to generate a precise, grounded response.

## ⚙️ Setup & Configuration

### 1. Database Schema
Run the following SQL to prepare your Oracle 26ai environment:

```sql
CREATE TABLE events_brazil_jug (
    id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    event_name VARCHAR2(255),
    full_description CLOB,
    event_date DATE,
    event_location VARCHAR2(255),
    registration_link VARCHAR2(500),
    vetor_embedding VECTOR(1024, FLOAT32)
);

CREATE VECTOR INDEX idx_jug_events_vector ON events_brazil_jug (vetor_embedding)
ORGANIZATION INMEMORY NEIGHBOR GRAPH
DISTANCE COSINE;
```

### 2. Environment Variables
For security reasons, sensitive data is injected via environment variables. Ensure these are set:

| Variable | Description |
| :--- | :--- |
| `DB_PASSWORD` | Password for the ADMIN user |
| `WALLET_PATH` | Path to the folder containing your TNS_ADMIN/Wallet |
| `OCI_COMPARTMENT_ID` | OCID of your OCI Compartment |
| `OCI_CONFIG_PATH` | Path to your `.oci/config` (Default: `~/.oci/config`) |

## 🚦 How to Use

### 1. Data Ingestion
Populate your knowledge base by sending a POST request to `/api/admin/saveAll` with the event details:

```json
[
  {
    "name": "Java Day Brasil 2024",
    "description": "The largest Java conference in Brazil featuring global speakers.",
    "date": "2024-11-20",
    "local": "São Paulo / Hybrid",
    "link": "https://brasiljug.com.br/javaday"
  }
]
```

### 2. Asking the Assistant
Interact with the assistant via `/api/v1/assistant/ask`:

**Request:** `"When and where is the next Java Day?"`

**Response:** `"The Java Day Brasil 2024 will take place on November 20th in São Paulo (Hybrid format). You can register here: https://brasiljug.com.br/javaday"`
